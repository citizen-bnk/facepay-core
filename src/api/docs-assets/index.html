SANDBOX ENVIRONMENT

This deployment uses demo accounts and simulated providers. No real money moves. Data can reset between server instances.

01 / AUTHENTICATE

Use the right identity.

Sandbox JWTs come from POST /v1/auth/login. Send Authorization: Bearer <token> with protected requests. Tokens have role-scoped permissions; a valid token does not grant every endpoint.

The console keeps your token in page memory only. Reloading clears it. The coding worker never receives it.

For your own integration, register and verify your email, subscribe at US$100/year, then create a key in your developer console. Paste the key below and use your console’s merchant and test-customer IDs in requests. Keys expire after one year, are revocable, require an active subscription, and allow 60 requests/minute.

02 / PAYMENT LIFECYCLE

Capture is the source of truth.

Create an intent → create a consent-linked verification session → confirm the intent → fetch its final status. Only captured with providerConfirmed: true means paid. authorised, processing and timeouts remain pending.

Use amountMinor: 12500 for R125.00. Supply a unique Idempotency-Key when creating an intent; reuse the same key and payload when retrying that operation.

03 / HANDLE FAILURES

Design for retries.

400 malformed JSON · 401 missing/expired token · 403 missing permission · 404 not found · 409 state/idempotency conflict · 422 invalid fields · 429 rate limit.

Errors use {"error":{"code":"…","message":"…"}}. Retry transient failures with exponential backoff and jitter. Fetch status after an uncertain payment result; never retry with a new idempotency key.

04 / INTEGRATE

Webhooks and typed clients.

Register an HTTPS destination through POST /v1/webhooks/subscriptions. The secret is returned once; keep it on your server. Delivery/signature verification is not implemented in this sandbox—poll intent status while testing.

The repository includes a TypeScript client at packages/sdk; it is not published to npm. Generate clients for other languages from the downloadable OpenAPI document. Raw biometric media is unavailable to all roles.
